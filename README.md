# anti-ai

Custom antislop skill collection for this project.

## Skills

- [`antislop-extended`](antislop-extended/SKILL.md) — Bahasa Indonesia copywriting tells, Indonesian UI localization, and anti-slop commit messages. Load together with the antislop core (`antislop.md`) and the concern skills (`antislop-ui`, `antislop-copywriting`, `antislop-code`).

## Install

Copy a skill folder into your skills directory (for example `~/.agents/skills/<name>/`), or install via `npx skills add cendysaputra/anti-ai`.
